Please consider our manuscript titled:

"Adaptive Edge-Cloud Inference with ONNX Deployment: A Reproducible Colab→Raspberry Pi Pipeline on CIFAR-100 and SVHN"

This work presents an open-source software pipeline that automates edge AI experiments from training to deployment. The software addresses three critical gaps in edge AI research: lack of portable measurement contracts, opaque preprocessing, and missing oracle baselines.

The pipeline provides:

1. Complete automation from Google Colab training to Raspberry Pi 5 deployment
2. Manifest-based reproducibility with JSON schema validation
3. Dual-context measurement (oracle vs. device) for performance gap analysis
4. Modular architecture supporting new models, datasets, and hardware platforms

The software artifact is fully open source (MIT License) and includes:
- Complete source code with 87% test coverage
- Comprehensive documentation (architecture, reproducibility guides)
- Three concrete reuse scenarios with working code
- Pre-trained ONNX models and experimental results
- Single-command execution scripts

Key contributions:
- Declarative manifests encoding all preprocessing parameters
- Automated deployment with environment setup and validation
- Synchronized telemetry collection (latency, throughput, temperature, power)
- Extensible design enabling researchers to benchmark new models on new hardware

The software has been validated through 36 configurations (4 models × 3 batch sizes × 3 thread counts) on Raspberry Pi 5, demonstrating reproducible performance measurements with <5% variance across runs.

Repository: https://github.com/manunicholasjacob/edge-ai-colab-to-pi-pipeline

We believe this work fits SoftwareX's focus on high-quality research software that enables reproducible computational experiments. The software provides general-purpose research infrastructure for edge AI experimentation, addressing reproducibility challenges that prevent fair comparison across studies.

The manuscript has not been published or submitted elsewhere. All authors have approved the submission and agree to the terms of SoftwareX.
